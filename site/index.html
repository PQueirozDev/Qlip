QLIP

Grave a tela e salve os últimos segundos do jogo com uma tecla. Nativo, leve e open source: o encoder da placa de vídeo faz o trabalho pesado.

F9 grava F10 liga o replay F8 salva o clipe

replay instantâneo

Aconteceu? Aperte F8.

Com o replay ligado, o Qlip guarda os últimos segundos já comprimidos pela placa de vídeo, em memória. O F8 salva esse trecho num MP4 e a gravação continua, sem pausa.

privacidade

Seu PC, seus vídeos.

Tudo roda local. Não existe conta, servidor nem telemetria.

sem conta
Abre e grava. Nada de login, assinatura, anúncio ou atualização obrigatória.
sem nuvem
Gravações e clipes ficam em Vídeos\Qlip. Nada sai do seu computador.
sem telemetria
O app não manda dados para lugar nenhum. O log fica numa pasta sua, em %APPDATA%\Qlip.
respeita DRM
Conteúdo protegido contra captura não é gravado, e o Qlip não tenta contornar isso nem anti-cheat.

código aberto

Leia, compile, mude.

O Qlip é open source sob a licença MIT. C++20 nativo, sem Electron e sem servidor local: captura pela GPU, encode pelo NVENC e escrita em disco em threads separadas.

  • C++20
  • Win32
  • Windows Graphics Capture
  • NVENC
  • FFmpeg (LGPL)
  • WASAPI
  • Direct3D 11
  • CMake

Achou um bug ou tem uma ideia? Abra uma issue ou mande um pull request.

PowerShell
# Visual Studio 2022 Build Tools + CMake 3.24+
git clone https://github.com/PQueirozDev/Qlip
cd Qlip
pwsh scripts/fetch-ffmpeg.ps1     # FFmpeg LGPL (headers, libs, DLLs)
cmake -S . -B build -A x64
cmake --build build --config Release
